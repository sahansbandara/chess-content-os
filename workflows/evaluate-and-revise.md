# Workflow: Evaluate and Revise

Use `skills/output-evaluator/SKILL.md`.

1. Load the project evaluation rubric.
2. Run hard validation.
3. Score the candidate output.
4. Revise failed areas only.
5. Repeat up to the configured maximum.
6. Send to human review when required.
7. Record the final result.

Do not mark an output complete without a pass, explicit human acceptance, or a documented limitation.
