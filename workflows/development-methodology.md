# Workflow: Development Methodology

## Purpose

Use strict execution flow after `PROJECT_MODE`.

Use `skills/development-methodology/SKILL.md`.

## Steps

1. Confirm `PROJECT_MODE`.
2. Inspect task context.
3. Brainstorm if unclear.
4. Present design/spec.
5. Write implementation plan.
6. Get approval for risky or architecture-impacting work.
7. Implement in small tasks.
8. Test/verify.
9. Review.
10. Handoff.

## Completion rule

Do not mark a task complete without verification or a clear statement that verification was not possible.
