# Workflow: Select LLM Provider

Use `skills/llm-provider-selector/SKILL.md`.

1. Confirm the project actually needs an LLM API.
2. Define task, modality, traffic, context, latency, privacy, and deployment requirements.
3. Refresh candidates from `https://github.com/cheahjs/free-llm-api-resources`.
4. Verify shortlisted candidates using official provider documentation.
5. Apply hard filters.
6. Score candidates.
7. Benchmark the top 2–3 using project-specific cases.
8. Select primary and fallback.
9. Define paid migration triggers.
10. Update provider documents and architecture decisions.

Do not recommend a provider as “best” without project-specific evaluation.
