# Workflow: Convert Demonstration to Skill

Use `skills/record-to-skill/SKILL.md`.

1. Read recording transcript or notes.
2. Extract ordered actions.
3. Extract decision and rejection rules.
4. Define exceptions and success criteria.
5. Create SOP.
6. Create skill package.
7. Add examples and evaluator.
8. Test on multiple cases.
9. Improve failures.
