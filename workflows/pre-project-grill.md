# Workflow: Pre-Project Grill Gate

## Purpose

Stress-test the project idea before final setup and before coding.

Use `skills/grill-project/SKILL.md`.

## Steps

1. Read `agent/BRIEF.md`.
2. Identify the weakest assumption.
3. Ask one hard question at a time.
4. Include recommended answer for each question.
5. Resolve MVP, user, main flow, stack, data, auth/security, deployment, and first milestone.
6. Update `agent/BRIEF.md`, `agent/TODO.md`, and `agent/DECISIONS.md`.
7. Continue to `workflows/new-project.md`.

## Do not

- write app code
- create fake certainty
- ask all questions at once
- switch to PROJECT_MODE until setup is clear
