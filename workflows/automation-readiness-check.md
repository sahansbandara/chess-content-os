# Workflow: Automation Readiness Check

Use `skills/automation-readiness/SKILL.md`.

1. Confirm manual workflow success.
2. Define trigger.
3. Define inputs and outputs.
4. Define success metrics.
5. Define retries and timeout.
6. Define failure notifications.
7. Define approvals.
8. Define logging and kill switch.
9. Run a limited test.
10. Approve or reject automation.
