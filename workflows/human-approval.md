# Workflow: Human Approval

Use `skills/approval-gate/SKILL.md`.

1. Describe the exact proposed action.
2. Classify risk.
3. Explain impact.
4. Explain rollback.
5. Request approval.
6. Execute only approved scope.
7. Record outcome.

No public publish, production deploy, destructive change, trade, payment, permission change, or secret change without explicit approval.
