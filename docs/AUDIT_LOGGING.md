# Audit Logging

## Required fields

- Run ID
- Timestamp
- Agent
- Task
- Workflow
- Input references
- Tools used
- Files changed
- Approval status
- Checks run
- Errors
- Final result
- Next action

## Never log

- Passwords
- API keys
- Access tokens
- Private keys
- Payment details
- Trading credentials
- Full sensitive user messages
- Private production data

## Retention and storage

Define per project.
