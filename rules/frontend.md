# Generic Frontend Rules

Use only for frontend projects. Do not assume React, Next.js, or vanilla JS unless selected.

## Required

- Responsive layout
- Accessible focus states
- Loading, empty, error, success states
- Semantic HTML where applicable
- No horizontal overflow on mobile
- Components should be reusable
- Use project design tokens from `design.md`

## Forbidden

- Framework-specific assumptions
- Placeholder-only UI marked as complete
- Inaccessible clickable divs
- Hardcoded secrets
