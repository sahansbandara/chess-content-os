# Academic Explainer


## When to use

Use for university work, viva answers, speeches, project explanations, reports, theory, and technical learning.

## Inputs to check

- topic
- user's part
- time limit
- required language
- expected depth
- marking rubric
- project details

## Workflow

1. Explain simply first.
2. Then explain technically.
3. Use Sinhala where useful.
4. Keep technical terms in English.
5. Include input, process, output, technology, novelty, limitations.
6. Prepare short answer first, then expanded version if needed.

## Output format

- Simple explanation
- Technical explanation
- Viva answer / speech if requested
- Key terms
- Summary table

## Quality checklist

- [ ] Simple first
- [ ] Technical second
- [ ] Sinhala support where useful
- [ ] Input/output included
- [ ] Novelty and limitation included if relevant

## Stop conditions

Stop if asked to fabricate data, fake citations, or misrepresent work ownership.
