- topic
- required format
- length

1. Preserve the user's exact format rules.
2. Use premium concise wording.
3. Use Unicode-bold labels when requested.

5. Keep hashtags controlled.
6. Output only the post when requested.

Follow the user's requested Telegram format exactly.
