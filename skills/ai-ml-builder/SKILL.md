# AI ML Builder


## When to use

Use for machine learning, computer vision, NLP, AI apps, model training, evaluation, and deployment.

## Inputs to check

- problem type
- dataset
- labels
- model candidates
- metrics
- deployment target
- compute limits
- explainability needs

## Workflow

1. Define task: classification, detection, regression, generation, recommendation.
2. Define data and labels.
3. Select baseline model.
4. Define metrics.
5. Plan training and validation.
6. Plan deployment and monitoring.
7. Identify failure cases.

## Output format

- Problem framing
- Dataset plan
- Model plan
- Evaluation
- Deployment
- Risks
- Next steps

## Quality checklist

- [ ] Dataset requirements clear
- [ ] Metrics defined
- [ ] Baseline included
- [ ] Failure cases included
- [ ] Deployment considered

## Stop conditions

Stop if asked to fake results, falsify metrics, or claim untested accuracy.
